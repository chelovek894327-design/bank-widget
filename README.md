📌 Описание проекта

Проект представляет собой backend-часть банковского виджета, который отображает последние банковские операции клиента.

Система позволяет:

маскировать номера банковских карт и счетов
фильтровать операции по статусу
сортировать операции по дате
форматировать дату для отображения
⚙️ Установка проекта
1. Клонировать репозиторий
git clone https://github.com/chelovek894327-design/bank-widget.git
2. Перейти в папку проекта
cd bank-widget
3. Установить зависимости (через Poetry)
poetry install
🚀 Запуск тестов
poetry run pytest
🧩 Основные функции
🔹 Маскировка номера карты
get_mask_card_number("1234567812345678")

📌 Результат:

1234 56** **** 5678
🔹 Маскировка номера счета
get_mask_account("12345678901234567890")

📌 Результат:

**7890
🔹 Фильтрация операций по статусу
filter_by_state(operations, "EXECUTED")

📌 Результат:

только операции со статусом EXECUTED
🔹 Сортировка по дате
sort_by_date(operations)

📌 Результат:

список операций, отсортированный от новых к старым
🔹 Форматирование даты
get_date("2024-03-11T02:26:18.671407")

📌 Результат:

11.03.2024
🔹 Маскировка строки карты/счёта
mask_account_card("Visa Platinum 7000792289606361")

📌 Результат:

Visa Platinum 7000 79** **** 6361
